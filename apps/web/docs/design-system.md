# GEMA Design System

Dark Technology theme for storefront + admin + AI.

## Tokens

- `src/styles/theme.css` — colors, radius, shadows, motion, layout
- `src/styles/animations.css` — fade/slide/shimmer + `prefers-reduced-motion`
- `src/app/globals.css` — primitives (`.btn-*`, `.input-field`, cards, badges, tables)

## Typography

- **Inter** — body (`--font-inter`)
- **Space Grotesk** — display / headings (`.font-display`)

## Brand colors

| Token | Value |
|-------|-------|
| Background | `#05070A` |
| Surface | `#0A0F14` |
| Cyan | `#00E5FF` |
| Violet | `#7C3AED` (accent only) |

## UI primitives

`src/components/ui/` — Button, Input, Card, Badge, Skeleton, Modal, Drawer, Tooltip, Toast

Icons: **Lucide**.

## Layout

- Store: sticky glass header, tech grid background, premium footer
- Admin: sidebar control center (same tokens)
